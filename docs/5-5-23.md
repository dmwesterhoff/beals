# x⁵ + y⁵ = z²³ has no non-trivial primitive solutions (unconditionally)

## Statement

**Theorem.** There are no integers x, y, z with xyz ≠ 0 and gcd(x, y, z) = 1 such that

  x⁵ + y⁵ = z²³.

All exponents are odd, so the same holds for the signatures (5, 23, 5) and (23, 5, 5). This settles the case (5, 5, 23) of Beal's conjecture.

## Status before this work

Stoll proved this assuming GRH: M. Stoll, *Chabauty without the Mordell–Weil group*, in: Algorithmic and Experimental Methods in Algebra, Geometry, and Number Theory, Springer 2017, 623–663, [arXiv:1506.04286](https://arxiv.org/abs/1506.04286), Theorem 8.8. It covers 7 ≤ p ≤ 53, but is unconditional only for p ≤ 19. Stoll's own 2024 lecture handout ([PDF](https://www.mathe2.uni-bayreuth.de/stoll/talks/Heidelberg2024-handout.pdf)) still lists p ≥ 23 as GRH-conditional.

**Novelty check (2026-10-09).** We found no unconditional proof for p = 23 in any of these:
- the survey [arXiv:2412.11933](https://arxiv.org/abs/2412.11933) v2, which lists (5,5,n) only for n ∈ {7, 19};
- Stoll's 2024 handout;
- the 12 papers that cite Stoll's paper, per Semantic Scholar;
- a web search.

The authors have not yet been asked to confirm.

## Proof

1. **Reduction** (Dahmen–Siksek, [arXiv:1309.4030](https://arxiv.org/abs/1309.4030), Lemma 3.1 and Prop. 3.3, both unconditional).
   - If 5 | z, there are no solutions, for every exponent (modular method).
   - If 5 ∤ z, a solution gives a rational point on Cₚ : Y² = 20Xᵖ + 5 other than ∞ and (1, ±5).
   - Cₚ is isomorphic to Stoll's curve C′ₚ : 5y² = 4xᵖ + 1, via Y = 5y. So it suffices to show C′₂₃(ℚ) = {∞, (1, 1), (1, −1)}.
2. **Stoll's criterion** (Prop. 8.5 in the form of Cor. 8.7).
   - Let L = ℚ(λ) with λ²³ = 2, and S ⊆ L({5}, 2) the subgroup cut out by the local image of J′(ℚ₅).
   - If S → L₂^×/L₂^{×2} is injective and its image avoids four explicit classes {1 + λ⁴⁵, 1 + λ²⁵/(1 + λ²), σ, σ′}, then C′₂₃(ℚ) consists of the three obvious points.
   - Hypothesis of Cor. 8.7: 23² ∤ 2²² − 1. This holds.
3. **The only GRH input in Stoll's proof** is the arithmetic of L needed for L({5}, 2): the class group (its 2-part) and the units (his §7–8). We replace it as follows.
   - **Cl(L) = 1, unconditionally.** We use Zimmert's bound (Invent. Math. 62 (1981), Satz 2, implemented in `certify/zimmert.gp` and checked against his table). For L of degree 23 and signature (1, 11) it is **273,676,831**; Minkowski's bound would be 1.65·10¹¹.
     - *Primary proof:* each of the **14,902,108** prime ideals of norm ≤ 273,676,831 has an explicit generator, verified by exact ideal equality. See `results/L23/generators/`; about 17 core-hours on an Apple M3.
     - *Supporting proof:* PARI's `bnfcertify` Phase 1, split into ranges over all 14,900,524 primes. See `results/L23/phase1/`.
     - The maximal order is certified with `nfcertify`, and all 67 factor-base primes have verified generators (`results/L23/setup.out`).
   - **L({5}, 2) is computed and verified independently** in `stoll/criterion.gp`. With h odd, its dimension is #S₅ + r₁ + r₂ = 2 + 12 = 14. Our 14 generators are shown to lie in L({5}, 2), by exact ideal factorization, and to be independent mod squares, by quadratic characters. So they form a basis, regardless of how they were found.
4. **The criterion, run in free software (PARI/GP).** `stoll/criterion.gp` is a reimplementation of Stoll's Magma computation, which was never published as code.
   - Square classes in L₂ are computed exactly, level by level; 2 is totally ramified. This is cross-checked against Hilbert symbols in the tests.
   - σ and σ′ are computed by halving points in J′(ℚ₂) (Stoll, Cor. 5.4(2)), with exact 2-adic square roots and an exact linear solve that is re-checked 2-adically.
   - The computed σ agrees with Stoll's Conjecture 8.6, an independent formula. This checks the halving code; it is not used in the proof.
   - **Result for p = 23** (`results/stoll/l23.out`, using the certified field data): dim S = 12, the map to L₂ is injective, none of the four classes is hit. **PASS.**

∎

## Validation of the implementation

- **Reproduces Stoll's Theorem 8.8:** PASS for p = 7, 11, 13, 17, 19 (unconditional in Stoll) and for p = 29, 31, 37, 41 (GRH, as in Stoll). See `results/stoll/`.
- **Internal checks run on every p:**
  - the image of the known point (1, 1) lies in S;
  - the 5-adic 2-torsion images are independent;
  - the L({5}, 2) basis is verified.
- **Tests** (`tests/test_stoll.py`):
  - known squares and non-squares at 2;
  - square-class bases of full dimension;
  - fast square classes agree with Hilbert symbols;
  - halving agrees with Conjecture 8.6;
  - the inclusion check detects classes that are in the image;
  - a regression case with compact units (p = 37).
- **Cross-check with Magma** (`results/L23/magma/psel5.transcript.txt`, public calculator): Magma's own L({5}, 2) for this field also has dimension 14, verified in the same way.

## What must be trusted

- **Published theorems:** Zimmert's Satz 2; Dahmen–Siksek's Lemma 3.1 and Prop. 3.3; Stoll's Prop. 8.5, Cor. 8.7 and Cor. 5.4.
- **PARI/GP 2.19.0:** exact ideal arithmetic (HNF), `nfcertify`, `idealfactor`, residue-field arithmetic, and exact rational linear algebra.
- **The correctness of our reimplementation of Stoll's criterion.** It is validated by reproducing all of Stoll's cases we ran, by agreement with his conjectured formula for σ, and by the tests above.

No step depends on GRH or on Magma.

## Reproducing

```sh
certify/build_pari.sh
FIELD=L23 .tools/pari/bin/gp -q -D parisizemax=2000000000 certify/setup.gp < /dev/null
FIELD=L23 .tools/pari/bin/gp -q -D parisizemax=1000000000 certify/units.gp < /dev/null
FIELD=L23 certify/run_chunks.sh generators     # ~2-3 h on 8 cores
FIELD=L23 certify/run_chunks.sh phase1         # ~1 h
python3 certify/check_results.py L23
STOLL_BNF=results/L23/field.bnf stoll/run_range.sh 23    # ~1 s
```
